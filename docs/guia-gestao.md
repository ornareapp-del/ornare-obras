# Guia da gestao

## Entrada diaria

1. Acesse `/login`.
2. Entre com e-mail e senha da equipe.
3. Abra o `Dashboard`.
4. Confira os cards de produtividade:
   - montadores em campo;
   - check-ins de hoje;
   - obras sem check-in recente;
   - fotos e checklist pendentes;
   - obras atrasadas, travadas ou com gastos perto da meta.

## Acompanhar uma obra

1. Abra `Obras`.
2. Selecione a obra.
3. Use as abas:
   - `Resumo` para visao geral;
   - `Cronograma` para fase, prazo e travas;
   - `Fotos` para aprovar e liberar imagens;
   - `Checklist` para acompanhar itens concluidos;
   - `Gastos` para controle financeiro;
   - `Ocorrencias` para problemas internos.

## Liberar fotos para cliente

1. Abra a obra.
2. Entre na aba `Fotos`.
3. Confira a imagem enviada.
4. Clique em `Aprovar`.
5. Depois clique em `Cliente`.
6. Confirme no portal do cliente se a foto apareceu.

Nunca libere foto com informacao interna, erro visivel ou registro que ainda precise de revisao.

## Liberar checklist para cliente

1. Abra a aba `Checklist`.
2. Confirme se o item esta concluido.
3. Clique em `Liberar ao cliente`.
4. Verifique no portal do cliente se o item aparece.

## Cuidar dos clientes

1. Abra `Equipe`.
2. Crie ou edite um usuario com perfil `Cliente`.
3. Vincule a obra correta.
4. Envie ou reenvie o acesso.

Cliente sem obra vinculada nao deve receber acesso.

## Exportar relatorios

1. Abra a obra.
2. Use os botoes de PDF.
3. Escolha o tipo correto:
   - `Cliente`: sem dados internos;
   - `Operacional`: execucao e pendencias;
   - `Executivo`: resumo gerencial;
   - `Financeiro interno`: gastos e meta.

## Fechamento do dia

1. Verifique obras sem check-in recente.
2. Revise fotos pendentes.
3. Revise checklist pendente.
4. Olhe gastos proximos ou acima da meta.
5. Registre decisoes importantes em ocorrencias ou cronograma.
