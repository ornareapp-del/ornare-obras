# Guia do cliente

## Acessar o portal

1. Abra o link enviado pela Ornare.
2. Informe seu e-mail.
3. Use a senha cadastrada ou escolha `Sou cliente / receber link`.
4. Abra o e-mail recebido.
5. Entre no portal.

O portal abre somente a obra vinculada ao seu usuario.

## Ver andamento da obra

1. Abra a aba `Obra`.
2. Confira status, fase e previsao.
3. Abra `Cronograma` para ver etapas liberadas.

As informacoes exibidas sao as que a equipe Ornare ja liberou para acompanhamento.

## Ver agenda

1. Abra `Agenda`.
2. Confira compromissos visiveis ao cliente.
3. Quando houver opcao de confirmacao ou reagendamento, envie a resposta pelo portal.

Reunioes internas nao aparecem no portal.

## Ver fotos

1. Abra `Fotos`.
2. Toque em uma foto para ampliar.
3. Use filtros quando houver muitas imagens.

Somente fotos aprovadas e liberadas pela equipe aparecem para o cliente.

## Mensagens

1. Abra `Mensagens`.
2. Leia comunicados da equipe.
3. Envie mensagem quando precisar responder ou pedir informacao.

Evite enviar dados sensiveis ou documentos pessoais por mensagem se a equipe pedir outro canal.

## Documentos e contatos

1. Abra `Docs` para documentos liberados.
2. Abra `Contatos` para falar com a equipe responsavel.

## Se nao conseguir entrar

1. Confira se digitou o e-mail cadastrado.
2. Use `Sou cliente / receber link`.
3. Verifique spam ou lixo eletronico.
4. Se ainda falhar, fale com a equipe Ornare.
